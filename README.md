# Firmware list for Home Assistant Raritan PX-Series PDU Integration

This repository maintains a reference list of firmware versions for a variety of Raritan PX-Series PDU models, intended **only** for internal use by the [Home Assistant Raritan PX-Series PDU Integration](https://github.com/exterrestris/home-assistant-raritan-px) to support firmware update notifications. Firmware files are **not** part of the repository and must be downloaded from Raritan directly

This list is in **no way affiliated, endorsed or supported** by Raritan or Legrand
